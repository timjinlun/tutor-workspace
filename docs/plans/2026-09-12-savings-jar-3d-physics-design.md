# 储蓄罐真实三维物理设计

日期：2026-09-12  
状态：已确认  
选择：Rapier 3D 刚体方案

## 目标

储蓄罐里的金币使用真实三维体积碰撞。金币从投币口落下时能够翻转、碰撞、滚动和堆叠；数量增加后形成中间略高、边缘自然摊开的币堆。拖动倾斜罐体时，金币受世界重力影响，在罐内重新滑动和堆积。

金额、币值、撤销、连续打卡和减少动态效果的既有规则保持不变。

## 物理架构

使用 `@dimforge/rapier3d-compat` 在渲染进程运行固定时间步的刚体世界：

- 每枚活动金币是动态刚体，碰撞体为与视觉网格尺寸一致的圆柱。
- 罐底使用固定圆柱碰撞体；圆周内壁由一组窄盒碰撞体组成，形成封闭容器。
- 罐盖只负责视觉表现。金币从投币口中央生成，避免盖面阻挡；金币进入罐体后由内壁和罐底约束。
- 拖动时罐体碰撞组与视觉模型使用同一旋转。世界重力保持向下，因此金币会随罐体倾斜移动。
- 使用 60 Hz 固定步长、连续碰撞检测和睡眠。没有活动刚体、拖动或反馈动画时，不保留动画循环。

## 有界表示

活动刚体数量上限保持 240。超过上限或长时间静止的金币合并进稳定币堆：

- 稳定币堆使用有限数量的三维金币网格表示，位置由确定性堆叠算法生成。
- 稳定堆顶提供固定碰撞面，后续落下的金币会与已有堆体接触。
- 堆叠算法按圆形层排布并向上收窄，中心略高，形成可从侧面观察的小山轮廓。
- 金额仍是唯一事实来源，不持久化刚体位置；重新启动时按金额重建确定性币堆。

## 渲染与交互

WebGL 金币着色器接受每枚刚体的平移与四元数旋转，视觉金币与 Rapier 圆柱碰撞体保持同步。罐体和碰撞容器共享倾斜四元数。

拖动分为两个阶段：按下并移动时更新罐体倾角；松手后保持倾角，金币继续运动直至休眠。倾角限制在侧边栏内可读的安全范围，避免罐体离开画布。

减少动态效果开启时，不运行落币或倾斜动画，金额变化后直接重建稳定币堆。

## 错误与降级

Rapier 初始化失败时保留金额文字和无障碍说明，并显示静态三维币堆；不会影响记账数据。WebGL 上下文丢失时停止物理循环，恢复后重建渲染资源和当前金额对应的稳定堆。

## 验证

- 单元测试验证金币为圆柱碰撞体、三维位置发生变化、金币之间无明显体积穿插、圆柱罐壁约束、堆顶中心高于边缘。
- 现有连续打卡、撤销、240 上限、减少动态效果和空闲零刷新测试继续通过。
- Electron 验收保存正面、侧面、落币中、堆积后和倾斜后截图；验证拖动后金币位置改变且最终休眠。
- 性能记录区分物理步进和 WebGL 绘制，目标是在当前验收机器上 240 枚活动金币保持流畅。

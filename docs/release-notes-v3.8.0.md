# 记一课 v3.8.0 · 新界面、能玩的金币堆、数据安全修复

## 新界面

- 全新视觉语言：墨绿黑板底、粉笔白字、金色的钱数；深色为主场，浅色是同一套墨色印在纸上。
- 数字改用系统自带的 DIN 并明显放大：今天页的记分牌、课程时间、收支金额、剩余课时。
- 强调色只留给「接下来」那节课和主按钮；按钮、标签不再全是胶囊，头像改成方的名章。
- 侧栏加了「记」字章；极光背景收成角落里很淡的光，「网格」改成整页方格本。
- 强调色、背景等已有设置全部保留。

## 金币堆

- 下落更像真硬币：会弹、会滑、翻着跟头从画面上沿掉进来，立着的会自己晃倒，地面有影子。
- 可以互动：捏住拖动再甩出去；点一下弹起来翻面；拖空白处转动视角。互动不改账目。
- 修复每次打卡动画结束后空跑上千步物理导致的卡顿。

## 修复

- 退出时可能丢失最后一次操作（150ms 防抖里的保存没有落盘，且数据库先于窗口关闭）。
- 把固定课改期到下周同一个星期几，会把那天本来的固定课顶掉。
- 备份到已存在的文件时报错「output file already exists」。
- 备份 / 导出的文件名日期按 UTC 计算，晚上会写成明天。
- 删除课程不检查班级引用；删除学员后仍留在班级名单里。
- 启动时恢复深浅色的脚本被 CSP 拦截，深色用户会闪一下浅色。
- v2 → v3 迁移改为单事务并先留独立备份；旧数据目录改为复制而不是搬走。

# 记一课 v3.8.1 · 修复碰金币后界面卡顿

## 修复

- v3.8.0 里只要点过或拖过金币堆，整个界面就会卡顿，松手几秒后还可能整段卡死。原因是一碰金币就把整堆两三百枚全部变回物理刚体，每帧算不过来。
- 现在只叫醒手边最多 28 枚（被碰的那枚、同层和压在它上面的），其余继续当固定底座。
- 超时结算不再同步快进物理：金币还在飞就继续等，基本不动了就原地定格。
- 掉帧时每帧最多补 2 步物理，不再越卡越算。

## 已知取舍

- 被扔出去的金币撞到远处没被叫醒的金币时，对方不会动。

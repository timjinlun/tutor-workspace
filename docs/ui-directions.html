记一课 · 视觉重构提案

四个方向，同一块界面

每个方向渲染的都是同一屏内容：侧边栏、本月三个数、九月考勤表、余额预警。内容完全一样，只有视觉语言不同，所以差异是可比的。挑一个，我就按它重构整个 App。

现在这版丑在哪

  • 蓝紫渐变（#3b82f6 → #8b5cf6）是 2022 年模板生成后台的标志配色，一眼认得出来
  • emoji 当图标（🔗 🗄 ➕ ✏️）—— 廉价感最主要的来源，且在 Windows 上渲染成另一套字形
  • 全屏圆角卡片加阴影，每块权重一样，看不出哪个重要，是一锅「卡片汤」
  • 字体是系统默认栈，数字没做等宽对齐，整列数字看着是歪的
  • 最要命的：考勤表是这个产品的核心，却长得像 Excel 截图，从没被当成主角设计过
A
教务纸本 Ledger
灵感来自老师真实在用的纸质点名册和教材印刷：暖纸底、贯通的账本格线、墨青色印章式打卡格。数字和标题用宋体，正文用无衬线。

适合

我的判断：A（教务纸本）

置信度 中高

你这个产品是卖给辅导老师的商品，不是自用工具。那视觉的第一任务就是「让老师一眼觉得这东西专业、值这个钱」，而不是「让我自己看着爽」。

B 最好看，但深色对非技术用户有距离感，而且截图发小红书的传播力明显弱。D 最实用但卖相撑不起价。C 最安全，问题是它安全到没有记忆点，做出来很可能被评价成「又一个飞书皮肤」。

A 的优势是它有一个别人没有的落点：老师对纸质点名册有肌肉记忆。暖纸底加账本格线，打开就知道这是干嘛的，上手成本最低，同时因为没人这么做后台，反而最不像模板生成的。这也是唯一一个视觉语言能直接反哺你商品详情页的方向。

选 A专业可信，最有辨识度，适合当商品卖
选 B最好看最像专业软件，但客群可能不买账
选 C最安全最好懂，代价是没记忆点
选 D信息密度最高，卖相最弱

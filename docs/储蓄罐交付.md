瞬时接口：`JarFeedback { seq, changes: { id, amount }[] }`，不进入 State/数据库。负 amount 表示撤销。
持久接口：`coinValue: { amount: number; month: string }`、`jarCapacity: number`；沿用现有 SQLite settings 键值存储，无新表。
